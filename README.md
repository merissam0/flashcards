# Flashcards

A tiny study tool in plain HTML, CSS, and JavaScript. No server, no build step; the deck is saved in the browser's `localStorage`.

- **Deck tab:** add, edit, and delete question/answer cards.
- **Review tab:** click the card or press `Space` to flip it. Press `K` for Known or `L` for Still learning. You can limit a session to cards still being learned.

## Run locally

Open `index.html` in a browser.

## Deploy to GitHub Pages

Push this folder to a repo, then go to Settings → Pages and serve from the branch root.

Note: the deck lives in each browser's own storage, so it doesn't sync across devices or browsers.
